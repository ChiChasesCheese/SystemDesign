CAPM's security market line states that an asset's expected return is a straight line in its beta alone: {{c1::E[Rᵢ] = Rf + βᵢ(E[Rm] − Rf)}}, where Rf is the risk-free rate, E[Rm] − Rf is the market risk premium, and βᵢ = Cov(Rᵢ, Rm) / Var(Rm) measures how much the asset's return moves with the market. The model's strong claim is that {{c2::beta is the only asset characteristic that should earn extra expected return}} — any two assets with the same beta should have the same expected return regardless of any other difference between them (size, valuation, industry, momentum), and any point off the line represents mispricing (positive alpha above the line, negative alpha below it) that should not persist if the model is correct and markets are efficient.

## zh
CAPM 的证券市场线（security market line, SML）主张，一项资产的预期收益是其 beta 的一条直线函数：{{c1::E[Rᵢ] = Rf + βᵢ(E[Rm] − Rf)}}，其中 Rf 是无风险利率，E[Rm] − Rf 是市场风险溢价，βᵢ = Cov(Rᵢ, Rm) / Var(Rm) 衡量该资产收益与市场共同变动的程度。这个模型的强主张是：{{c2::beta 是唯一应当带来额外预期收益的资产特征}}——任何两项 beta 相同的资产，无论在其他方面有什么差异（规模、估值、行业、动量），预期收益都应当相同；任何偏离这条线的点都代表定价错误（在线上方是正 alpha，线下方是负 alpha），如果模型正确且市场有效，这种偏离不应当持续存在。
