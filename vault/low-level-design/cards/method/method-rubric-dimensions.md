## Q
Beyond "does the core flow work," name four axes a machine-coding rubric scores.

## A
- **Extensibility / separation of concerns** — can the follow-up requirement land in one place?
- **Readability** — intention-revealing names, small methods, no dead code.
- **Testability** — injected dependencies, a demoed test or driver.
- **Driving the session** — narrated trade-offs, re-scoping out loud, handling probes.

Working code is the gate; these four separate hire from strong-hire.
